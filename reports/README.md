# Reports archive

Monthly GCC/UAE banking sector ratings reports land here, one file per month:
`<YYYY>-<MM>.md` (e.g. `2026-06.md`).

Each report summarizes publicly available rating actions, outlooks, and
commentary from **S&P Global Ratings**, **Fitch Ratings**, and **Moody's
Ratings**, focused on the **UAE banking sector** with broader GCC context.

- Structure: see [`TEMPLATE.md`](./TEMPLATE.md).
- How reports get generated: see
  [`../docs/scheduled-trigger-setup.md`](../docs/scheduled-trigger-setup.md).
